# Piercer Clipbase — Snippet & Prompt Vault

Cofre de snippets, comandos, respostas rápidas e prompts com variáveis dinâmicas

## Funcionalidades

- **Seções principais**: Novo Snippet
- **Ações disponíveis**: Exportar JSON, + Novo Snippet, Excluir, Cancelar, Salvar
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8114`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8114`.
